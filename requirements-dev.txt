# === Hinweise ===
# 
# 1. Lokaler CI Status:
#    - 'skip' Status: Zulässig wenn Tool nicht installiert
#    - 'fail' Status: Sollte vermieden werden (bedeutet Tool-Fehler)
#    - 'pass' Status: Ideal, Tool läuft erfolgreich
#
# 2. Mindestanforderungen für lokalen CI:
#    - Python 3.10+
#    - Hauptpaket 'codepipeline' muss importierbar sein
#    - Grundlegende Tests sollten laufen können
#
# 3. Tool-spezifische Hinweise:
#    - ruff: Linter für Python Code, konfiguriert in pyproject.toml
#    - mypy: Type Checker, konfiguriert in mypy.ini (falls vorhanden)
#    - pytest: Test Runner mit Coverage, konfiguriert in pyproject.toml
#    - semgrep: SAST Scanner, erfordert separate Installation
#    - bandit: Python Security Scanner
#    - gitleaks: Git Secret Scanner, erfordert separate Installation
#    - pip-audit: Python Dependency Vulnerability Scanner
#
# 4. MVP-Verhalten:
#    Das System ist so konzipiert, dass es auch ohne alle Tools funktioniert.
#    Fehlende Tools werden als 'skip' markiert und beeinträchtigen nicht
#    den Gesamtstatus 'overall: pass' des lokalen CI.
